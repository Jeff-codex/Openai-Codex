# 공개 페이지 디자인 정리 — 2026-10-18

## 범위와 기준

기존 정보 구조, 본문, 파란 캐릭터와 로고를 유지하면서 공개 페이지 24개의 타이포그래피, 버튼, 간격과 모바일 내비게이션을 정리했다. 회원·관리자 화면과 `/review`는 이번 변경 대상에 포함하지 않는다.

- 기준 커밋: `d031fa74ba351f5b4c1eab78253618d190b76659`
- 원격 백업: `backup/everyonepr-before-design-20261018`
- 운영 사이트의 공개 HTML 25개, CSS/JS 2개, 브랜드 이미지 3개를 기준 커밋과 비교했다. HTML의 Cloudflare beacon, 줄바꿈 및 문서 경계 공백만 정규화했을 때 30개 모두 일치했다. 이 결과는 서버 코드나 DB 데이터의 동일성을 입증하지 않는다.

## 변경 내용

- 저장소 폴더를 `딜리버(DELIVER)`에서 `모두의피알(EveryonePR)`로 변경하고 루트 ignore, pre-commit 경로와 README를 맞췄다.
- 제목의 좁은 글자 수 제한을 제거하고 한국어 단어 단위 줄바꿈을 적용했다.
- 공통 주요 버튼의 파란색을 DESIGN.md 기준 `#0038B8`로 통일하고 광택과 그림자를 줄였다.
- 카드 간격, 내부 여백, 키보드 포커스 표시를 정리했다.
- 모바일 헤더에 접이식 메뉴와 회원가입 진입점을 추가했다. 기존 링크와 이벤트 핸들러를 재사용하며 인증 상태를 따로 저장하지 않는다. JavaScript가 실행되지 않으면 기존 내비게이션이 남는다.
- 공개 HTML의 본문 `<main>` 및 기존 인라인 스크립트는 유지했다.

## 배포 전 확인 및 복구

현재 Production 배포, DNS 변경, DB 쓰기를 수행하지 않았다. Cloudflare 프로젝트 `dliver`, D1/KV/R2 식별자와 배포 스크립트는 그대로다.

외부 Cloudflare Git 연동의 Root directory가 옛 폴더명을 지정하는지는 미확인이다. 병합 전에 실제 배포 방식과 Root directory를 확인하고, 해당 설정을 사용하는 경우 새 폴더명으로 변경한 Preview에서 배포·주요 이동 경로를 검증한다. 저장소 내부 배포 스크립트는 프로젝트 상대 경로를 사용한다.

운영 반영 후 복구가 필요하면 기존 Cloudflare 배포로 롤백하고, 이 PR의 변경을 되돌린다. 폴더명을 되돌리면 외부 Root directory 설정도 함께 맞춘다. 백업 브랜치에는 변경 전 커밋이 보존되어 있다.
